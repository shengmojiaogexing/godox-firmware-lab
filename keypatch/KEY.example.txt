私有密钥（16 位 CC2500 同步字）—— 示例模板
=============================================

本文件是**示例**，不要直接使用里面的密钥（0xD798 已被广泛公开）。

用法：复制成 keypatch/KEY.txt 再改成你自己的密钥。
KEY.txt 已被 .gitignore 忽略，永远不会进入 git 仓库；示例文件才会入库。

    Copy-Item keypatch\KEY.example.txt keypatch\KEY.txt

格式
----
key    = 0xD798   (十进制 55192)      # 16 位，合法范围 0x0001..0xFFFE
SYNC1  = 0xD7                          # 高字节 = key >> 8
SYNC0  = 0x98                          # 低字节 = key & 0xFF

生成一把新密钥（在仓库根目录运行）
----------------------------------
    tools\python\python.exe keypatch\keypatch.py keygen
    tools\python\python.exe keypatch\keypatch.py keygen --passphrase "你的口令"

给所有设备打同一把密钥（灯 + 引闪器必须一致）
----------------------------------------------
    tools\python\python.exe keypatch\keypatch.py patch-all --key 0xD798 --verify
    # 需要 G3 V2.0 容器备用件时再加 --container

规则与限制
----------
- 灯和引闪器**必须使用同一把**密钥；换密钥后所有设备都要重打补丁并重新刷机。
- 工具会自动拒绝这些值：
  * 原厂设备能产生的 100 个公开同步字（`50024/(ID+1)`，ID=0..99）；
  * 保留/危险值 0x0000、0xFFFF、0xAAAA、0x5555、0x8000。
- 16 位同步字挡的是"正常原厂设备误触发"，不是密码学认证。
- 不要把真实密钥提交进 git；本机明文保存于 keypatch/KEY.txt 即可。
