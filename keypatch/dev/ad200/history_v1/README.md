# v1（固定密钥版）历史归档

v1 = 需求升级前的过渡版本：**灯/引闪器同步字恒等于私有 KEY**（没有开关）。
v2（当前交付）改为「灯 ID=OFF(0) → KEY；ID=1..99 → 原厂 50024/(ID+1)」，
本目录保留 v1 的验证日志，便于对照与回退。

## v1 补丁（AD200 Pro V1.60，已被 v2 取代）

| 地址 | 文件偏移 | before | after | 说明 |
|---|---|---|---|---|
| 0x0800B9B0 | 0x89B0 | `41 1c` | `01 21` | `adds r1,r0,#1` → `movs r1,#1`（除数恒 1） |
| 0x0800B9E0 | 0x89E0 | `68 c3 00 00` | KEY 小端 + `00 00` | 被除数 50024 → KEY |

v1 成品 sha256（KEY=0x6B21）：`21f6eab507c86ee468665e640c2ead96668e0f08e9c5cdc98c7fad3d32d3a5ca`
（v2 成品不同，见 ../NOTES.md；`keypatch/out/AD200pro_V1.60_key6B21.bin` 现在是 v2 产物。）

## v1 验证结论（日志在本目录）

- `keypatch patch --verify` 9/9 PASS；
- Unicorn 调用级：ID=0/1/37/99 恒写 KEY，原厂镜像自证 `50024//(ID+1)`；
- 静态：全镜像只有 `rf_chip_config` 与 `0x0800B9AC` 写 SYNC1/SYNC0；
- 整机模拟器：两镜像均 80,000 条指令到主循环，再跑 200 万条 PC 采样完全一致。

## v2 与 v1 的差异

| 项 | v1 | v2 |
|---|---|---|
| 灯 ID=0 | KEY | KEY（密钥模式） |
| 灯 ID=1..99 | KEY（也恒为 KEY） | 原厂 `50024/(ID+1)`（普通模式，可被原厂引闪器引闪） |
| 补丁形态 | 2 处 2 字节替换 | 整段改写 0x0800B9AC..0x0800B9E4 共 56 字节 |
| SCAL + 1ms 延时 | 保留 | 删除（只改同步字不改频率），仅保留 delay_us(20) |
