## 2. 固件身份 / 帧缓冲 / 显示链路

- 镜像基址 `0x08003000`（`vector[1] = 0x080030D5`），88,032 B。
- 帧缓冲 **`0x200007C4`**：12 条带 × `0xA8`(168) 字节 = **2016 B = 168×96 单色像素**
  （每个条带 = 8 行；字形绘制 `0x080070F4` 写 `fb + row*0xA8 + col` 与 `+0xA8` 两字节 = 16 行高）。
- LCD 刷新：`0x08014E88(page)` 每次刷 3 个条带（3×0xA8）；显示任务 `0x0800680C`
  每 5 帧里 4 次 flush（page 0..3 → 12 条带）、第 5 帧重绘（`bl 0x0801472C`）。
- 验证：`cfn_menu.py` §2 打印 `0x08014E88` 的 5 个调用点（1 个初始化 + 4 个轮流刷新）。

## 3. 字体 / 图元与绘制原语

| 地址 | 语义（由脚本反汇编/自证） |
|---|---|
| `0x08016208` | 8×16 字体/图元表，**17 B/字形**：宽度(1B) + 16B（每列 2B = 16 像素高） |
| `0x08015EBA` / `0x080161AE` | 8×8 字体（9 B/字形），底部按钮文字用本表 |
| `0x080070F4(r0=行条带, r1=列, r2=字形, r3=移位)` | 画 8×16 字形（C.Fn 的全部文字） |
| `0x0800703C` / `0x08007070` | 画 8×8 字形（SCAN 的进度数字、CLEAR 按钮文字等） |
| `0x08007728` / `0x08007764` | 画 16×16 位图（表 `0x08017334` / `0x08017314`，TX 项的两个值） |
| `0x08005260` | 列表选中行整行反显（XOR `0x7F`/`0xFF`，x=1..0x40） |
| `0x08005440` | 编辑态：把当前值/选项行反显（XOR，x=0x4E..0x80；仅当 `[0x200004F1]==1`） |
| `0x08006E38` | 底部按钮框 + 8×8 标签（x=0/0x2A/0x54/0x7E；第一个按钮 = **CLEAR**） |

字形索引 → 字符的映射由脚本自证：索引 `0`-`9`=数字、`10`-`35`=`A`-`Z`、`36`-`61`=`a`-`z`、
`62+`=符号（`0x40='.'`、`0x44='/'`、`0x41='→'` 等）。顶栏 “C.Fn”
（字形 `0x0C,0x40,0x0F,0x31`）与 “Ver2.0”（`0x1F,0x28,0x35,0x02,0x40,0x00`）解码结果
与预期完全一致（`cfn_menu.py` §1 两条 PASS）。

## 4. C.Fn 画面结构（渲染函数 `0x08004914`）

```
page = idx >> 2 ; slot = idx & 3          ; 0x080049B8 / 0x080049BC
page 0 → 项 0..3 ; page 1 → 项 4..7 ; page 2 → 项 8..0xB
```

- 顶栏（y=0..15）：左 “C.Fn”，右 “Ver2.0”。
- 列表（y=16..79，左栏 x=0..64 有框）：当前页 4 行名称，行高 16px；
  选中项行（slot 0..3 → 文本行 1..4）被 `0x08005260` 反显成黑底白字（文字变成“洞”）。
- 值/选项栏（x≈80..127）：箭头（字形 `0x41`）画在 `x=0x50`，选项文字从 `x=0x5A` 起；
  箭头所在行 `row = 2*value + 4`（即文本行 = value+2）。
  编辑态时 `0x08005440` 再把选中值行反显（矩形 x=0x4E..0x80）。
- 底部（y=80..95）：4 个按钮框（x=0/0x2A/0x54/0x7E），第一个标签 **CLEAR**，其余为空框；
  另有 `0x08007620` 在右下叠一个 16×16 图标。
- 反汇编证据：`0x08004914`（入口）、`0x080049B2..0x080049CA`（页拆分/分派）、
  `0x08004C4C`（page 1）、`0x08004FAC`（page 2）、`0x0800525A..0x08005292`（反显收尾）。

补充证据（关键反汇编，完整清单见日志 §4.5/§6）：

- ID 项（`0x08004E86` 起）：先画标签 `ID`；`ID!=0` 走 `/10`、`%10` 两位数字；
  **`ID==0` 走 `0x08004F2C` 分支，在值行画 `0x18 0x0F 0x0F` = “OFF”**，随后画箭头并反显。
- CH（`0x08004E4A`）：`settings[5]+1` 后 `/10`、`%10` 两位数字。
- 最大值表 `0x08018362` 字节（文件偏移 `0x15362`）：
  `01 01 01 01 01 1F 63 01 02 06 01 01`（index 9=6 为 LCD，index 6=0x63=99 为 ID）。
- 编辑态反显：数值项（CH/ID）调用 `0x08005440(0)` 反显固定值行；选项项调用
  `0x08005440(settings[idx])` 反显选中选项行（脚本 §4.3 均有 PASS 断言）。

## 6. 导航 / 改值（Unicorn 行为级验证）

`cfn_menu.py` §5 用真实执行 `0x0800D3D8`（+）/`0x080061CC`（-）验证：

- `[0x200004F0]=1`（C.Fn 打开）且 `[0x200004F1]=0`（非编辑）时：
  `+` 序列 `0→1→…→0xB→0`，`-` 序列 `0→0xB→…→0` —— **12 项全部可达，无隐藏项**。
- `[0x200004F1]=1`（编辑）时：按 `0x08018362` 最大值回绕
  （`max→0`、`0→max`）；**只有 LCD(index 9) 是钳位**（`6` 处 `+` 仍为 6，0 处 `-` 仍为 0）。
- 每次按键还会：把画面超时计数设为 `0x7D0`、把保存倒计时 `0x20000532` 设为 **200**、
  `0x2000055A=0x28`（脚本断言 PASS）。
- 改值副作用：
  - `ID`（index 6）改动会调用同步字函数 `0x080121BC(新ID)`（脚本：36→37 时实参 = 37，PASS）；
    另外在项导航落到 index 6 时也会调用一次（`0x08006236/0x0800D46C` 的 `cmp #6`）。
  - `TX`（index 0xB）改动后 `settings[0xB] → RAM 0x200004F5`（PASS）。

## 7. 按键路径（从主界面到改值/退出）

以下由静态反汇编 + 桩化行为验证得到（日志 §6）：

1. **按键矩阵**：任务 `0x0800DCDC` 扫描 3 列（GPIOC `0x48000C00` 列选）＋ 行读
   GPIOC/GPIOB（`0x48000800` bit6），得到键码（1/4/8/0x40/0x0C/0x10/0x80…），
   存 `[UI+8]` 后分派（`0x0800DF1A`）。
2. **进入/退出 C.Fn**：键码 **8** 分支（`0x0800DF5C`，前置 `[0x20000550]==0`）→
   `0x080053F4`：**切换** `[0x200004F0]`（1=显示 C.Fn），同时清 `[0x200004F1]`、
   `[0x200004DB]`、`settings[4]`，必要时停掉扫描。
   → 同一个键可以“进 C.Fn / 再按退出”。**返回键（键码 1）** 走 `0x0800DC14` 关闭。
3. **选择项**：`[0x200004F0]=1` 且 `[0x200004F1]=0` 时，`+/-` 改 `[0x200004F2]`（0..0xB）。
4. **进入编辑**：`SET` 键 `0x08012058`：若 `[0x200004F1]==1` 且当前项为 SCAN(4) 且
   `settings[4]==1` → 调 `0x0800FB2C`（开始扫描）；否则 `[0x200004F1] ^= 1`（进/出编辑态）。
5. **改值**：编辑态 `+/-` 写 `settings[idx]`，带最大值回绕（§6）。
6. **保存**：改值后 `0x080114CC` 把倒计时 `0x20000532` 设为 200；主循环 `0x080114A8`
   递减到 0 → 置 `0x20000534=1`；保存任务 `0x0800E9A0` 调 `0x08005EF0` 组记录
   （settings[0..1]→rec+0x2C、[2..5]→+0x30、[6..9]→+0x34、[10..13]→+0x38），
   再 `0x08015304` 比较/复制 shadow 后写 flash（镜像中引用 flash `0x0801F000`）。
   **⇒ C.Fn 的 12 个字节本来就会持久化，复用项不需要新增保存代码。**
7. **超时**：`0x080121F4` 维护 `[0x20000478+0xA]` 倒计时（每次按键重置 0x7D0）。

> 说明：固件里没有“MENU/SET/+/-”这些丝印字符串；上面的键名是按**键码功能**与同代
> 神牛 UI（AD100/AD200：MENU 进 C.Fn、SET 进编辑、+/- 改值）推断的，物理按键位置需实机确认。

## 8. 复用现有 C.Fn 项做“密钥开关”：是否零 UI 改动？

**结论：是，零 UI 改动即可被用户看到和操作。**

理由与证据：

1. **没有隐藏/预留项**：渲染函数按 `idx>>2` 分页、`idx&3` 选择行，12 项全部有名称并全部可选中
   （`+/-` 行为验证 0..0xB 循环，§6）。与 AD100 原型“新增第 3 页 KEY 项”不同，V1C 不需要
   改绘制/翻页/导航代码。
2. **现方案（ID=0 → 私有 KEY）本身就是 C.Fn 项**：
   `C.Fn → 第 2 页第 3 行 “ID” → 右栏 “OFF”`。
   ID≠0 时右栏显示两位十进制（如 `37`），ID=0 时显示 **`OFF`**（`0x08004F2C` 分支，
   字形 `0x18 0x0F 0x0F`）。因此用户**能直接看到当前是否处于密钥模式**。
   这是对 `keypatch/dev/v1c/AUDIT.md` §8 遗留问题（“ID=0 是否真是用户可见的 OFF”）的
   **UI 侧正面回答：是**。
3. **如果希望“ON=密钥模式”的直觉语义**，可选复用任一个 ON/OFF 项（都无需改 UI：

   | 候选 | index | 显示位置 | 右栏语义 | 复用影响 |
   |---|---|---|---|---|
   | `BEEP` | 7 | 第 2 页第 4 行 | `OFF`=0、`ON`=1（推荐“ON=开”） | 关闭蜂鸣功能（8 处读者：`0x08003AEA` 等） |
   | `FEB ACL` | 10 | 第 3 页第 3 行 | `ON`=0、`OFF`=1（反向） | 语义不详（“FEB …”），低风险 |
   | `AF` | 1 | 第 1 页第 2 行 | `ON`=0、`OFF`=1（反向） | 关闭 AF 辅助光 |
   | `RX STBY` | 3 | 第 1 页第 4 行 | `60min`/`30min`（不是 ON/OFF） | 不直观，不建议 |

   注意：`V1C` **不显示 F1..F12 编号**，用户文档只能用“第 N 页第 M 行 + 名称”定位。
4. **持久化免费**：§7.6，改值后 200 tick 自动写 flash，记录里包含全部 12 个 C.Fn 字节。

**用户操作说明建议（若沿用现方案：ID=0 → 密钥模式）**

> **密钥模式**：按 MENU 键进入 C.Fn 画面 → 用 `+/-` 选到第 2 页第 3 行 **ID** →
> 按 SET 进入编辑（选中行反显）→ 用 `-` 把数值减到 **OFF** → 再按 SET 退出 →
> 约几秒后自动保存（断电前也可再等一会）。
> **普通模式**：同一位置把 ID 调到 1..99（右栏显示两位数字）。
> 判定：C.Fn 中 ID 右栏为 **OFF** = 密钥模式；为数字 = 普通模式（同步字 = 50024/(ID+1)）。

若改选 **BEEP** 作为开关，则说明改写为：`C.Fn → 第 2 页第 4 行 BEEP → ON = 密钥模式`。


- 12 项是 **3 页 × 4 行**：page0 = `m/ft, AF, STBY, RX STBY`；page1 = `SCAN, CH, ID, BEEP`；
  page2 = `LIGHT, LCD, FEB ACL, TX`。选中第 5/9 项时整页换成 page1/page2。
- 实拍式逐像素证据：`devices/v1c/re/log_cfn_menu.txt` §7 有 6 张全帧 ASCII
  （`idx=0`、`idx=3`、`idx=6 ID=0 → OFF`、`idx=6 编辑态`、`idx=8 LIGHT`、`idx=11 TX`），
  每张为 168 列 × 96 行，`#`=点亮。例如 `idx=6, ID=0` 的帧缓冲可直接看到：
  左栏第 3 行（ID）整行反显、右栏 `row4` 处 “OFF”、底部 “CLEAR”。

## 10. 与 AD100 / AD200 方案对照

| 项目 | AD100 Pro（原型） | AD200 Pro（已支持） | **V1C（本报告）** |
|---|---|---|---|
| C.Fn 项数/页 | 6 项，3 行/页 | 8 项（F1..F8），一页 | **12 项，4 行/页 × 3 页** |
| 项编号显示 | `F1..F6` 等 | `F1..F8` | **不显示编号，只显示名称** |
| 复用做 KEY | 新增第 3 页 KEY 项（需改 UI） | 复用第 8 项 F8（零 UI 改动） | **复用 index 6 `ID`（现方案即可，零 UI 改动）；或 BEEP/FEB ACL** |
| 值行选择显示 | 文字 | 文字 ON/OFF | 箭头 + 文字，编辑态反显 |

## 11. 风险 / 未确认

1. **物理按键丝印**无法从固件恢复（只能确定键码功能）；`MENU/SET/+/-` 的名称是推断，
   实机验证时请以“进入 C.Fn 的那个键 / SET 键 / 两个 +/- 键”描述为准。
2. **项 10 名称逐字为 `FEB ACL`**（字形 `0x0F 0x0E 0x0B 0x0A 0x0C 0x15`，中间有空格），
   固件无文字解释其含义；只知道它是 ON/OFF 两档、`0=ON / 1=OFF`。
3. `SCAN`(4)/`LCD`(9)/`TX`(11) 的右栏是状态/图标显示（含 8×8 数字网格、16×16 位图），
   本报告给出绘制调用与关键地址，未做逐像素人工核对。
4. 保存链路中 `0x08015304` 是“记录比较/复制 shadow”，真正 flash 写函数在其后
   （镜像引用 flash `0x0801F000`），本报告未逐条展开；但“改值 → 200 tick → 记录含全部
   C.Fn 字节 → 写 flash”的链路已确认。
5. `settings[0xB]` 改值后写入的 `RAM 0x200004F5` 语义（疑与 CH 生效值相关）未确认。
6. 画面重建用 Unicorn 真实执行渲染函数，但 RAM 初值（按键/电池/无线状态等）按 0 设置，
   因此顶栏状态图标等“运行态”内容与实机可能不同；**C.Fn 列表/值本身由代码+settings
   决定，可信度高**。
