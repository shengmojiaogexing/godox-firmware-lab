0. 结论摘要（详见各节证据）
==============================================================================

  1) C.Fn 列表渲染函数 = 0x0800431C（0x0800431C..0x08004D03，2536 B）；
     唯一调用点 0x0801219E（画面分派任务 0x08012124 内，[0x200004D4]==1 时）；
     页/槽位：page = idx>>2、slot = idx&3（0x080043C2 / 0x080043C4）。
  2) 帧缓冲 0x200007AC（12 条带 x 0xA8 = 2016 B = 168x96）；
     8x16 字形表 0x080143D6（17B/字形），8x8 表 0x08014088 / 0x0801437C（9B/字形）；
     列表选中行反显 = render 内联 0x08004B76..0x08004BFC；
     编辑态值行反显 = 0x08004D50；LCD 刷新 0x08012880（每次 3 条带）。
  3) 真实执行渲染函数得到：本机型 C.Fn 只有 10 项（idx 0..9）：
     m/ft, AF, STBY, RX STBY, SCAN, CH, ID, BEEP, LIGHT, LCD。
     其中 LIGHT(idx8) = 12sec/OFF/ON 三档（max=2，默认 0=12sec，settings 0x20001058+8）。
     FEB ACL / TX 两项在本机型 UI 中不存在（最大值表里仍留有它们的 2 个字节）。
  4) 按键：键码 8 切换 C.Fn（0x08004D04）、返回键(1) 0x0800CCB0、SET 0x08011454、
     +/- 0x080058E4 -> INC 0x0800C528 / DEC 0x080059E4；每次按键保存倒计时
     0x20000516=200，tick 0x080109A4 -> 标志 0x20000518 -> 任务 0x0800D9C8 ->
     写 flash 0x0801F000。

9. 结论
==============================================================================

  一、C.Fn 列表页 = 渲染函数 0x0800431C（画面分派 0x08012124，
      [0x200004D4]==1 时在 0x0801219E 调用）：page = idx>>2、slot = idx&3。
      每页 4 行“名称”（左栏，文字约居中于 x≈30），选中行整行反显（内联
      0x08004B76..0x08004BFC）；右栏 x≈0x50 是箭头、0x5A 起是文字；
      编辑态再用 0x08004D50 反显选中值行。无平滑滚动，越界即换页。
      没有 F1..F12 编号，只显示名称。

  二、10 项（index -> 名称 / 右栏 / 取值 / max / settings 字节）：
       0  m/ft     m | ft                                         0=m, 1=ft                              max=1   settings=0x20001058
       1  AF       ON | OFF                                       0=ON, 1=OFF                            max=1   settings=0x20001059
       2  STBY     月亮图标 + ON | OFF                                0=ON, 1=OFF                            max=1   settings=0x2000105A
       3  RX STBY  60min | 30min                                  0=60min, 1=30min                       max=1   settings=0x2000105B
       4  SCAN     OFF | START（state 1/2 进度数字，state 3 2x4 结果网格）   动作项，SET 在 settings[4]==1 时启动扫描         max=1   settings=0x2000105C
       5  CH       两位十进制 = settings[5]+1                          0..31 -> 显示 01..32                     max=31  settings=0x2000105D
       6  ID       OFF (ID=0) | 两位十进制 01..99                      0=OFF，1..99 直接显示                       max=99  settings=0x2000105E
       7  BEEP     喇叭图标 + OFF | ON                                0=OFF, 1=ON                            max=1   settings=0x2000105F
       8  LIGHT    12sec | OFF | ON                               0=12sec, 1=OFF, 2=ON；出厂 0              max=2   settings=0x20001060
       9  LCD      竖排 -3..+3 刻度（表 0x08015A48，箭头固定 row6 指当前档）      0..6 -> -3..+3，上限钳位                    max=6   settings=0x20001061

  三、按键路径：
      MENU 类键（键码 8）-> 0x08004D04 切换 C.Fn 画面（同一个键再按退出）；
      返回键（键码 1）-> 0x0800CCB0 关闭；
      +/- 键（GPIOB 0x48000800 bit7/8，0x080058E4）-> 未编辑时移动项（0..9 循环），
      编辑态时改值（按 0x08016102 最大值表回绕，item9 LCD 钳位）；
      SET 键（0x08011454）-> 切换编辑态 0x200004D5（SCAN 特例：settings[4]==1 时启动扫描）。
      改值后保存倒计时 [0x20000516]=200（0x080109C8），tick 0x080109A4；
      到 0 置 0x20000518=1 -> 任务 0x0800D9C8 -> 记录 0x08010D94 -> flash 0x0801F000。

  四、与 V1C（12 项）的关键差异：
      · 本机型 C.Fn 只有 10 项（0..9），FEB ACL / TX 不存在；
        最大值表仍保留 12 字节（平台共用），[10]/[11] 只被全局钳位循环使用。
      · 顶栏版本号 "Ver1.1"（V1C 为 "Ver2.0"）；渲染函数 0x0800431C（V1C 0x08004914）。
      · UI 变量整体前移：SCREEN 0x200004D4 / EDIT 0x200004D5 / SEL 0x200004D6
        （V1C 0x200004F0/F1/F2）；settings 基址 0x20001058（V1C 0x20001086）。
      · 帧缓冲 0x200007AC（V1C 0x200007C4）；8x16 表 0x080143D6（V1C 0x08016208）。
      · 最大值表 0x08016102（V1C 0x08018362），字节完全一致。
      · INC/DEC/SET/开关/返回/保存链路结构同 V1C，地址不同（见下表）。

  五、风险 / 未确认：
      · 物理按键丝印无法从固件恢复；“MENU/SET/+/-”是按功能与同代 UI 推断。
      · SCAN 的 state=1/2 进度与 state=3 网格只给出真实绘制证据，未逐像素核对。
      · 画面重建时 RAM 初值按 0 设置，顶栏状态图标与实机可能不同；
        C.Fn 列表/取值本身由代码 + settings 决定，可信度高。

  全部检查: PASS
