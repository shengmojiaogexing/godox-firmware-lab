# V1S 静态证据与复现（补丁点定位过程）

本文记录 Godox V1S（`V1S_V1.8.bin`，78,500 B，sha256 `87a06000…`）补丁点的定位过程与
可复现脚本，供复核 / 换固件版本时重新定位用。结论汇总见 [`../README.md`](../README.md)，
完整证据见 [`../re/SYNC_ANALYSIS.md`](../re/SYNC_ANALYSIS.md) 与 [`../re/CFN_ANALYSIS.md`](../re/CFN_ANALYSIS.md)。

> 环境：仓库根便携 Python `tools\python\python.exe`（capstone 5.0.7 / unicorn 2.1.4）。
> 固件：`devices/v1s/firmware/V1S_V1.8.bin`（本机，未改动，sha256 见上）。

---

## 1. 先定镜像基址

1. 向量表前 8 字节：`init_sp = 0x20001540`（RAM）、`reset = 0x080030D5`（Thumb）。
2. Reset 桩 `ldr rX,[pc]; blx rX; ldr rY,[pc]; bx rY` 全镜像唯一，位于文件偏移 `0xD4`：
   `0x080030D4`；由 `vector[1] = 0x080030D5` ⇒ **base = `0x080030D4 - 0xD4 = 0x08003000`**。
3. `__main` 桩（`mov sp, r0`，其字面量 == MSP `0x20001540`）唯一位于文件偏移 `0xC0` ⇒ 同样得 base = `0x08003000`。
4. 字面量池交叉验证：全镜像 Flash 指针字面量无一落在 `0x08003000` 以下。

## 2. 定位「ID → 同步字」函数（从常量 50024 入手）

1. 搜 4 字节小端字面量 `68 c3 00 00`（= 50024）→ 全镜像唯一，文件偏移 `0xE310`（虚拟 `0x08011310`）；
2. 找引用它的 `ldr rX,[pc,#imm]` → 函数入口 **`0x080112DC`**（`ldr r2,[pc,#0x30]`）；
3. 反汇编：`adds r1,r0,#1`（分母 ID+1）→ `bl 0x080030F0`（uidiv）→ 两次 `WriteReg(4/5)` →
   `delay(20)` → `strobe(0x33)`（SCAL）→ `delay(1000)` → `pop {r4,pc}`；
4. 函数共 **56 字节**（`0x080112DC..0x08011313`），下一函数 **`0x08011314`**；
5. 全镜像运行期写 reg4/5 只有本函数（`0x080112EE`/`0x080112F6`）与 init 表 `0x080133FC`
   （`0x0801342A`/`0x08013432`）；RF init `0x08005DE4` 保证 init 值被覆盖。

复现脚本：`re/sync_v1s.py`（89 项断言，含 Unicorn 调用级自证）。

## 3. 定位 C.Fn / settings（从最大表字节模式入手）

1. V1C 的 12 字节 max/回绕表 `01 01 01 01 01 1F 63 01 02 06 01 01` 在本固件内容相同，
   全镜像唯一命中 **`0x08015DE6`**；
2. 找引用该表的 `ldr` 字面量 → 反向找引用点：dec handler `0x08005A82`、inc handler `0x0800C3B2`、
   合法性 clamp `0x0800EE2E`；
3. 反汇编两个 handler，找到 `ldr r0,=0x20001054`（settings 基址）后的动态索引访问
   `ldrb/strb [r0, item]`；`cmp #0xB` 给出 12 项边界；item6=ID、item8=LIGHT；
4. 由 `cmp r1,#6` 门 → 门后 `ldrb r0,[r0,#6]; bl 0x080112DC` 确认 item6 即 ID，
   且门条件就是「只有改 ID 才重设同步字」；
5. 沿 settings[8]（`0x2000105C`）找读者 → 造型灯任务 `0x08003950` 的 `0x08003956`/`0x0800397E`
   （GPIO `0x48001000` bit13/14）；菜单渲染 `0x0800431C` 的 `0x08004A8A/9A`（只显示，不改）；
   save `0x0800582E`；写者仅出厂默认 `0x08005EC4`、按键工厂复位 `0x0800CEAA`、上电 load `0x0801397C`。

复现脚本：`re/cfn_v1s.py`（144 项断言，含数据流反向切片与 mask/gate 字节校验）。

## 4. 一键复现

```powershell
# 仓库根
tools\python\python.exe devices\v1s\re\sync_v1s.py    # → 89 PASS / 0 FAIL
tools\python\python.exe devices\v1s\re\cfn_v1s.py     # → 144 PASS / 0 FAIL
tools\python\python.exe keypatch\keypatch.py patch --device v1s --key 0xD798 --verify --out %TEMP%\kp_v1s
```

## 5. 关键字节速查

| 项 | 地址 / 字节 |
|---|---|
| 同步字函数（原厂 56 B） | `0x080112DC`，`0c4a10b5…68c30000` |
| 50024 字面量 | `0x08011310` = `68 c3 00 00`（唯一） |
| C.Fn max 表 | `0x08015DE6` = `01 01 01 01 01 1F 63 01 02 06 01 01` |
| settings 基址 | `0x20001054`；ID=`0x2000105A`；LIGHT=`0x2000105C` |
| dec gate | `0x08005A8A` = `06 29 02 d1` |
| inc gate | `0x0800C3E8` = `06 29 f5 d1` |
| 造型灯读者 #1/#2 | `0x08003956` = `00 7a`；`0x0800397E` = `01 7a` |
| 出厂默认函数 | `0x08005E68`；item8 默认 `0` @`0x08005EC4` |
| save builder / load 展开 | `0x080056F0` / `0x0801383C` |
