## 3. 实机安全阶梯（风险自负）

1. **原厂回滚确认**：能从官网重下 `V1S_V1.8.bin` 同版本；官方 G3 升级软件能识别设备；
2. **最小补丁**：刷本补丁后开机，确认菜单/触控正常；LIGHT 保持出厂 `12sec` 时，用原厂引闪器
   （任意 ID 0..99）能正常引闪（= 普通模式无回归）；
3. **密钥模式**：灯 C.Fn LIGHT 设为 `ON`；用刷了同一 KEY 的引闪器引闪 → 正常；
4. **隔离验证**：引闪器切回原厂普通模式（原厂 ID / 原厂固件）→ 密钥模式的灯应**不被引闪**；
5. **恢复**：灯 LIGHT 设回 `12sec`/`OFF` → 回到原厂公式、原厂引闪器可引闪；
6. **出厂复位**：确认按键组合恢复默认后 LIGHT 回 `12sec`（普通模式）——这是忘记密钥时的恢复路径；
7. 任何一步异常，立刻刷回原厂。

## 4. 已知风险 / 未确认

- **无实机验证**：mask 后造型灯行为、CC2500 对「只写 SYNC1/0、不 SCAL」的接受度都只能靠真机确认；
- 去掉 `SCAL(0x33)+1ms` 是唯一射频差异 → 若上电首包丢失，优先怀疑此处（回退方案见 README §4.1）；
- LIGHT 原厂造型灯功能被复用（固定 12sec 档），需要在用户文档里写清楚；
- 只对 V1S V1.8 有效，换版本必须重新定位（见 `../docs/01_静态证据与复现.md`）。
