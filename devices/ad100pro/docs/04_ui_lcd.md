> 固件基址 0x08003000；`main()` = 0x0800CF74；主循环 1 ms 节拍在 0x0800D010。

## 2. LCD 驱动

### 2.1 引脚与写字节（0x0800A480）

```c
/* 0x0800A480 */ void lcd_write_byte(uint8_t b, int is_data)
{
    GPIO_WriteBit(GPIOB, 1<<7,  is_data);   /* PB7 = A0/DC：1=数据 0=命令 */
    GPIO_WriteBit(GPIOB, 1<<9,  0);         /* PB9 = CS 低 */
    for (int i = 0; i < 8; i++) {           /* MSB first */
        GPIO_WriteBit(GPIOB, 1<<6, 0);      /* SCLK 低（BRR） */
        GPIO_WriteBit(GPIOA, 1<<10, (b & 0x80) != 0);  /* PA10 = SI */
        GPIO_WriteBit(GPIOB, 1<<6, 1);      /* SCLK 高（BSRR） */
        b <<= 1;
    }
    GPIO_WriteBit(GPIOB, 1<<9, 1);          /* CS 高 */
    GPIO_WriteBit(GPIOB, 1<<7, 1);
}
/* 0x080047BE */ void lcd_cmd(uint8_t c)  { lcd_write_byte(c, 0); }
                 void lcd_data(uint8_t d) { lcd_write_byte(d, 1); }
```
> 注：0x080047BE 的参数序为 `(r0=is_data, r1=byte)`，内部换序后调用 0x0800A480。

### 2.2 初始化（0x0800C954，由 0x0800D088 调用）

| 命令 | 参数 | 含义（SH1106/SSD1306 族） |
|---|---|---|
| 0xAE | – | 显示关 |
| 0x02 | – | 列地址低 4 位 = 2（132 列控制器居中 128 显示区） |
| 0x10 | – | 列地址高 4 位 = 0 |
| 0x40 | – | 起始行 = 0 |
| 0xB0 | – | 页地址 = 0 |
| 0x81 | 0xFF | 对比度/亮度 = 0xFF |
| 0xA1 | – | 段重映射（左右镜像） |
| 0xA6 | – | 正常显示（非反白） |
| 0xA8 | 0x3F | 复用率 = 64 行 |
| 0xAD | 0x8B | DC-DC 控制（SH1106 典型 0x8B=开） |
| 0x33 | – | 泵电压档（SH1106 0x30–0x33） |
| 0xC8 | – | COM 扫描方向反向 |
| 0xD3 | 0x00 | 显示偏移 = 0 |
| 0xD5 | 0x80 | 时钟分频 |
| 0xD9 | 0x1F | 预充电周期 |
| 0xDA | 0x12 | COM 引脚硬件配置（交替） |
| 0xDB | 0x30 | VCOMH 取消电平 |
| 0xA0 | – | 段重映射恢复（最终方向） |
| 0xC0 | – | COM 扫描恢复 |
| 0xAF | – | 显示开 |

初始化链：`0x0800D088` → `0x0800D134`（GPIO/电源准备）→ `0x0800C954`（命令表）→ `0x0800B5C0`（清屏+刷新）。

### 2.3 帧缓冲与刷新

- 帧缓冲：**0x200004CC – 0x200008CB（1024 B）**，布局 = `page(0..7) * 128 + x(0..127)`；
  每字节 = 该页 8 个纵向像素（bit0 在上）。
- 清屏 `0x0800B5C0`：
  ```c
  for (page = 0; page < 8; page++)
      memset(FB + page*128, 0, 128);
  lcd_flush();                 /* 0x0800A30C */
  ```
- 刷新 `0x0800A30C`：
  ```c
  lcd_cmd(0xB0);               /* 页 0 */
  for (i = 0; i < 128; i++) lcd_data(FB[i]);
  lcd_cmd(0xB1);
  for (i = 0; i < 128; i++) lcd_data(FB[128 + i]);
  ... 共 8 页 ...
  ```
  （每页发送前调用 0x08004670(0) 做片选/总线互斥处理 /*?*/）
- 局部刷新/脏页：由调用者先改 FB 再调用 0x0800A30C；`0x0800A30C` 无条件刷全屏，
  主循环中由 UI 任务控制刷新频率 /*?*/。

### 2.4 字库与绘制例程

- 字形记录格式（由 0x08004E1C 证明）：
  ```
  struct glyph { uint8_t width;  uint8_t bitmap[8]; };   /* 9 字节；bitmap 每字节垂直 8 像素 */
  ```
- 画字函数 `0x08004E1C(page, x, glyph_index)`：
  ```c
  /* 0x08004E1C */
  void lcd_draw_glyph(int page, int x, int idx)
  {
      const struct glyph *g = (const struct glyph *)(GLYPH_BASE + idx*9);
      uint8_t *dst = FB + page*128 + x;
      for (int i = 0; i < g->width; i++)
          dst[i] = g->bitmap[i];      /* FB 直接写；调用方负责刷新 */
  }
  ```
  同类例程（各自 bank/索引固定）：0x08004E4C、0x08004E98（基址 0x0800DE6C）、
  0x08004EE4/0x08004F30（0x0800DEC6）、0x08004FC4（0x0800EBBA）、0x08005058（0x0800EBA8）、
  0x08005090/0x080050C8/0x08005120/0x08005158/0x08005190/0x080051C8/0x08005200/0x0800523C/
  0x08005274/0x080052AC/0x080052E4/0x0800531C …（图标/大数字）。
- 字形数据 bank：从 **0x0800DB0C** 起是 9 字节记录数组（例如 0x0800DB0C = `04 FE 82 82 FE …`，
  即宽 4 的“0/O”类字形）。0x0800DB0C–0x0800F448 之间是若干 bank + 图标位图（低熵区）。
- 数字/功率条：0x0800A570 计算功率百分比后查表 0x0800D4C6（u16 表，打包两段位域），
  得到显示参数写 0x200001D8/0x200001C8；0x08006770 查功率映射表 0x0800D174（或 +0xA2 的 32 位表）。
- 其他参数表：0x0800DA2E（各组默认功率步进 28 字节）、0x0800DA9A（RF 功率表，见 docs/03）、
  0x0800D164（时钟/参数表，被初始化 0x08007798 引用）。

## 3. 按键：矩阵扫描 + 事件

### 3.1 扫描（0x08008D00，主循环任务，约每 1 ms 调一次，内部 5 次分频）

```c
/* 0x08008D00 核心结构（简化） */
static uint16_t scan_keys(void)
{
    uint16_t k = 0;
    /* 阶段 1：PB3 拉低，读列 PC10/PC11/PC12 */
    GPIO_Config(GPIOB, PIN_3, OUT_OD); GPIO_Write(GPIOB, 1<<3, 0);
    delay_ms(3);
    if (!GPIO_Read(GPIOC, 1<<10)) k |= 0x001;
    if (!GPIO_Read(GPIOC, 1<<11)) k |= 0x002;
    if (!GPIO_Read(GPIOC, 1<<12)) k |= 0x004;
    /* 阶段 2：PB4 拉低，读 PC10/PC11 */
    ... k |= 0x008/0x010 ...
    /* 阶段 3：PB5 拉低，读 PC10/PC11 */
    ... k |= 0x020/0x040 ...
    /* 阶段 4/5：读 PC7、PD4 等（扩展键） */
    ...
    return k;
}
```
- 行：**PB3、PB4、PB5**（开漏输出，逐行拉低，其余行释放）。
- 列：**PC10、PC11、PC12、PC7、PD4**（输入，扫描前配置上拉 /*?*/）。
- 每次扫描产生 16 位键值位图；主循环里 5 次扫描做稳定判定（`[0x20000164+0xa]` 分频计数）。

### 3.2 去抖 / 长按 / 事件分发（0x08008D00 尾部）

- 状态区：**0x20000164**（UI 状态结构，约 0x34 字节）。
  - `+0x2c` 上次键值（u16），`+0x09` 按下标志，`+0x0a` 扫描分频，
  - `+0x0b` 长按计数（>50 次 ≈ 长按），`+0x0c` 长按锁存，`+0x0d..0x10` 各键单次/长按标志。
- 键值 → 动作（0x08008F5E 起的 switch）：

| 键位 | 动作函数 | 备注 |
|---|---|---|
| 0x001 | `[+0xf]=1`（设置键标志） | |
| 0x002 | 0x0800C068 | /*?*/ |
| 0x004 | 0x0800983C | 菜单/模式相关 |
| 0x010 | `[+0xd]=1` | |
| 0x020 | 0x0800B6A0 | 菜单切换 |
| 0x080 | `[+0x10]=1`（长按/组合标志） | |
| 0x100 | 0x08004484 | |
| 0x200 | 0x08004B74 + `rf_set_id(RAM_20000480[5])` | **改 ID/信道后重设同步字** |
| 0x400 | 0x0800A91C（电源） | |
| 0x021 | 组合键：翻转 `[+3]` 标志 | |
| 0x080/0x102 等 | 0x0800B880 / 0x08004B74 | |

- 长按：键值稳定后计数 `[+0xb]` 超过 50（≈50 ms 级）→ `[+0xc]=1` 并触发 0x0800B7F0/0x0800B578 等。
- 按键“按下/释放”边沿经 EXTI 中断辅助（见 §5）与定时扫描共同判定。

### 3.3 其他输入

- **PC14/PC15**：0x080047CC（主循环任务）直接读这两个脚并驱动状态机
  `[0x20000184+5]∈{0x0d,0x0e}` → 0x08008A5C / 0x08004880（疑似拨动开关/电池盖/热靴检测 /*?*/）。
- **PA6**：射频模块 GDO2/状态（见 docs/03）。
- **充电检测**：PC3（输出使能）、PC4（充电状态输出），见 §4。

## 4. 电池与充电

### 4.1 ADC 采样

- ADC 初始化：**0x08009310**（主循环 init，配置 ADC+DMA 结构 0x200003AC，内部使用 0x08006878）。
- ADC/DMA 完成中断：IRQ9 DMA1_CH1 = **0x08004790** → 0x08006E2C(0x200003F8)。
- 采样结果：**0x2000020A**、**0x2000020C**（u16，两路电压：电池 / 另一路 /*?*/）。
- 辅助函数：0x080069AC（ADC 初始化/校准）、0x08006878（ADC 通道/CCR 配置 + 转换触发）。
  0x08006878 对 ADC_CCR(0x40012708) 操作 TSEN/VREFEN/VBATEN 位（通道 0x10/0x11/0x12 = 温度/VREFINT/VBAT）。

### 4.2 电量 / 充电状态机

- 调度：0x0800A230（主循环任务）每 20 次（≈20 ms）调用一次 0x0800A140、0x0800A034；
  同时把 **PC3=1**、按状态置 **PC4**（充电使能/LED /*?*/）。
- `0x0800A034`：处理 0x2000020A 的电压 → 更新 0x2000021C 结构（`[0]`/`[3]`/`[4]`/`[0xa]` 状态字段）。
  - 电压 > **0x3B6 = 950**（ADC 原始值）→ 充满/高电平时计数；
  - 电压 < 0x14 → 极低；
  - 中间区间用 **float64 比较**（软浮点 0x0800339C/0x080033F4，常量 0x405CA583… / 0x69098C81…），
    即按电池放电曲线分档（/*?*/ 具体曲线值与百分比映射未展开）。
- `0x0800A140`：处理 0x2000020C（第二路，疑似充电电流/温度检测），同样分档，常量 0x4058BE8D…/0xFDAFFC4D…。
- 低电/关机：0x0800A230 在 `[0x200001B2]==0x1A` 或 `[0x200001BC]==0x1A` 时提前返回（保护状态）；
  0x0800A91C → 0x0800A934 执行关机/低功耗序列。
- 结果字段 `RAM_2000021C[0..0xb]`：`[0]`/`[1]` = 电池1/2 档位，`[2]` = 充电状态，`[9]` = 分频计数器，
  UI 读取这些字段显示电量格。

### 4.3 电源序列

`0x0800A934(on)`（主循环初始化时以 1 调用，0x0800A91C 用于关机）：
关中断 → 逐路配置/拉低 GPIOC（PC5、PC?）、PA（PA6/PA0 等）、GPIOF、GPIOB，延时后置位；
末尾调用 0x0800B9C0 启动射频/系统任务。0x0800B814 为另一入口（/*?*/ 唤醒/复位路径）。

## 5. 中断与主循环（与 UI 相关部分）

| 中断 | 入口 | 与 UI 的关系 |
|---|---|---|
| IRQ5 EXTI0_1 | 0x08005A78 | 线 0：充电/电源状态输入（读 `[0x20000175]&3`、`[0x20000480+1]`），事件→0x08006014/0x0800B7F0 |
| IRQ6 EXTI2_3 | 0x08005B00 | 线 3：清挂起（0x080072AC(8)），用途 /*?*/ |
| IRQ7 EXTI4_15 | 0x08005B0C | 线 15=RF GDO0 收包；线 6=PA6 状态（延时 50 µs 后读） |
| IRQ13 TIM1 | 0x0800BA7C | 0x080083E8(0x20000294)（TIM1 超时事件） |
| IRQ15 TIM2 | 0x0800BA8C | 0x080083E8(0x200002D0) |
| IRQ19 TIM14 | 0x0800BA44 | 0x080083E8(0x20000348) 等 |
| SysTick | 0x0800B8E4 | 1 ms 节拍：置 `[0x200001E1]=1`；tick 计数 `[0x20000104]`（0x08007434 读） |

主循环（0x0800D010）每 1 ms 依次调用：
`0x080074F0`(喂狗) → `0x08008D00`(按键/UI) → `0x080047CC`(PC14/15 状态机) → `0x080098F8` →
`0x080035A8` → `0x0800642C` → `0x080038C0` → `0x0800D098` → `0x080065CC` → `0x0800896C` →
`0x0800B394` → `0x0800A230`(电池/充电) → `0x08003BAC` → `0x0800C7D4`(RF 保活) →
`0x0800B7B0` → `0x080097F8` → `0x0800B80C`。

LCD 初始化在启动路径：`0x0800D088` 调用 `0x0800D134`（GPIO/电源）、`0x0800C954`（命令表）、
`0x0800B5C0`（清屏）；主循环中 UI 任务修改 FB 后调用 `0x0800A30C` 刷新。

## 6. 与用户仓库的对照 / 复用

- 用户仓库 `components/stage_ui` 为 ESP32 端 UI，与 AD100 Pro 本机 UI 无直接代码对应；
  本机 UI 全部为自绘点阵 + 每字形一个绘制例程的紧凑实现。
- 功率显示：本机 `0x08006770` 的功率映射表 + 0x0800D174 与用户仓库“功率 1/1–1/256、步进 1/10 档”
  的语义可互相校验（表 0x0800DA2E 的 28 字节约等于各组默认档位）。
- 信道/ID 显示：`rf_set_id()` 与用户 `godox_encode_id()` 一致（见 docs/03）。

## 7. 待确认问题

1. **LCD 控制器确切型号**：命令集（0xAD/0x8B、0x33、0xD9/0xDA/0xDB）与 SH1106 最吻合，
   但 0xA0/0xC0 的最终方向与 SSD1306 也兼容；需实机/照片确认（列偏移 2 强烈指向 132 列控制器）。
2. **字库 bank 组织**：0x0800DB0C 起为 9 字节记录；0x0800D164 起另有一批表（部分 16/32 位），
   需逐表确认（含 0x0800D174、0x0800D35A、0x0800D4C6、0x0800D590、0x0800D808）。
3. **键位到物理按键名的映射**：矩阵位（bit0–bit10）与“MODE/SET/+/-/电源”等丝印的对应需结合外壳/实机。
4. **电池曲线**：两个状态机的 float64 常量（0x405CA583、0x69098C81、0x4058BE8D、0xFDAFFC4D 等）
   尚未解出具体电压阈值/百分比公式；ADC 原始值→电压的换算系数（VDDA/分压比）未确认。
5. **充电控制引脚语义**：PC3/PC4 的具体功能（充电使能 vs 充电 LED vs 电流档）待确认。
6. **蜂鸣器/LED**：未发现明确 PWM 驱动；可能由 GPIO 直驱或与 0x0800A6xx 电源时序耦合 /*?*/。
7. **局部刷新策略**：0x0800A30C 全屏刷新，实际 UI 是否会做页级局部刷新需在仿真中观察。
8. UI 菜单状态机（0x20000164 结构各字段含义、0x08008A5C 的功率/多组编辑逻辑）需结合仿真逐步确认。
