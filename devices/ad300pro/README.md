# Godox AD300 Pro（V1.30）逆向档案

AD300 Pro 是神牛 AD 系列 300Ws 外拍灯，2.4 GHz 链路同样使用 TI CC2500 兼容收发芯片，
固件把引闪 ID 换算成 16 位硬件同步字（`sync = 50024 / (ID + 1)`）。

本目录记录 **AD300pro_V1.30.bin**（44,220 B，
sha256 `e3be6a63…98765932`）的静态逆向结论与补丁规格；
补丁实现见 [`keypatch/devices/ad300.py`](../../keypatch/devices/ad300.py)，
用户可见开关是 **C.Fn 第 8 项 `F8`（原厂「稳定色温模式」OFF/ON）**。

> ⚠️ 先读仓库根 [`DISCLAIMER.md`](../../DISCLAIMER.md)。固件不随仓库分发；
> 刷机有风险，请先确认官方 G3 能识别设备并保留同版本原厂固件回滚。
> **本设备无整机模拟器、无实机验证**；离线验证 = 静态检查 + Unicorn 调用级（47 项）。

## 2. 「ID → 同步字」函数（补丁核心）

```c
// 原厂 0x0800B548，56 字节（0x0800B548..0x0800B57F，下一函数 0x0800B580）
void rf_set_id(uint8_t id) {          // 入参 = settings[6]（当前 ID）
    uint32_t sync = 50024 / (id + 1);
    CC2500_WriteReg(4, sync >> 8);    // SYNC1
    CC2500_WriteReg(5, sync & 0xFF);  // SYNC0
    delay_us(20);
    CC2500_WriteStrobe(0x33);         // SCAL
    delay_us(1000);
}
```

- 原厂 56 字节（可运行 [`keypatch/dev/ad300/audit_cfn.py`](../../keypatch/dev/ad300/audit_cfn.py) 复跑取证）：

  ```text
  0c4a10b5 411c1046 f7f7cefd 0446010a 042000f0 8effe1b2 052000f0 8aff1420
  00f04afe 332000f0 e5ff7d20 c00000f0 43fe10bd 68c30000
  ```

- 全镜像 `50024 = 0xC368` 字面量**唯一**，位于 `0x0800B57C`（函数 +0x34）。
- 只有本函数与 CC2500 初始化表（`0x0800C2xx` 区域，先于本函数执行）写寄存器 4/5。
- 本函数 4 个调用点：`0x0800467A`（C.Fn 递减）、`0x080048CE`（RF init）、
  `0x08008428`（C.Fn 递增）、`0x08008872`（按键任务），入参都是 `settings[6]`。
- 辅助函数：`__aeabi_uidiv`=`0x080030F0`、`CC2500_WriteReg`=`0x0800C47A`、
  `strobe`=`0x0800C53C`、`delay_us`=`0x0800C200`。

补丁把它整段改写成「`F8=1` → 同步字 = 私有 KEY；否则原厂公式」，只写 SYNC1/0
（去掉 SCAL + 1ms 延时，理由与风险见 §5）。

## 3. C.Fn 菜单与开关选择

- C.Fn 共 **8 项**：`+/-` 处理函数（`0x080045E8` 递减 / `0x08008388` 递增）里
  item `0 ↔ 7` 回绕；**item 6 = ID（最大 99）**，item 7 最大 = 1。
- 最大值/回绕表 `0x0800DA64` 前 8 字节：`01 02 03 96 02 01 63 01`
  （item7 最大 1 ⇒ 二进制 OFF/ON；item6 最大 `0x63`=99 ⇒ ID 0..99）。
- **item 7 = C.Fn 第 8 项 `F8`**，原厂功能是「稳定色温模式」（OFF/ON）：
  `F8=1` 时切换到另一套闪光时长 / 能量 / 标定表（6 处功能读者，见 §4）。
- 出厂默认 `settings[7] = 0`（普通模式），设置随原厂参数记录持久化。

用户可见语义（本补丁）：

| C.Fn F8 | 同步字 | 效果 |
|---|---|---|
| **OFF**（出厂默认） | `50024 / (ID+1)` | 原厂普通模式，任何原厂引闪器都能引闪 |
| **ON** | 私有 KEY | 只有刷了同一把 KEY 的引闪器能引闪；原厂引闪器 ID 公式对不上 |

## 4. 补丁点清单（`keypatch/devices/ad300.py`）

| # | 地址 | 原厂 → 补丁 | 说明 |
|---|---|---|---|
| 1 | `0x0800B548` | 56 B 整函数改写 | 读 `settings[7]`；`1` → KEY，`0` → 原厂公式；只写 SYNC1/SYNC0 |
| 2 | `0x08004677` | `d1` → `d3` | 递减 handler gate：`cmp r2,#6; bne` → `blo`，item≥6 改值立即重设同步字 |
| 3 | `0x08008425` | `d1` → `d3` | 递增 handler gate：同上（item 6=ID / item 7=F8） |
| 4 | `0x08004B08` | `c9 79` → `00 21` | 显示/数值表：F8=1 不切备用时长表 |
| 5 | `0x08004DC8` | `c0 79` → `00 20` | 显示页：F8=1 不改页面标志/清 UI bit4 |
| 6 | `0x08005980` | `c9 79` → `00 21` | 测量/待机路径：F8=1 不切备用表 |
| 7 | `0x08006062` | `d2 79` → `00 22` | level 查表：F8=1 不切备用标定表 |
| 8 | `0x0800ADBC` | `db 79` → `00 23` | muldiv/缩放：F8=1 不改功率/时长缩放 |
| 9 | `0x0800AEA0` | `d2 79` → `00 22` | RF 远程设置：F8=1 不改设置分叉 |
| 10 | `0x0800B6C8` | `d1 71` → `00 bf` | 退出/模式切换路径：不再静默清 `settings[7]`（防密钥开关被关） |

> 第 4–9 项把原厂「稳定色温模式」的读者固定成常数 0（等价 F8=OFF 分支）；
> **F8=OFF 时与原厂逐指令行为一致**，F8=ON 时原厂稳定色温功能不生效。
> 第 10 项是必须的：原厂退出路径会 `strb 0,[settings+7]`，不复用会悄悄关掉密钥开关。

持久化证据：参数记录 builder `0x08004410` 把 `settings[0..3]` 写记录 `+0x18`、
`settings[4..7]` 写记录 `+0x1C`（最高字节 = F8）；保存函数 `0x0800B38C` 写
flash `0x0801F000 + slot*100`；加载函数 `0x0800C814` 回填 `settings`。

## 5. 验证与风险

离线验证（`keypatch.py patch --device ad300 --key 0xD798 --verify`）：

- 静态：长度 44,220 B 不变；56 B 函数体/字面量/11 处补丁点逐字节匹配；
  与原厂差异 **恰好** 只落在补丁点（63 字节）。
- Unicorn 调用级（47 项全 PASS）：
  - 补丁版同步字函数：F8=1 → `WriteReg(4,KEY>>8)`/`WriteReg(5,KEY&0xFF)`；
    F8=0 → `50024/(ID+1)`（ID=0/1/5/37/99）；
  - 原厂镜像自证：`WriteReg(4)/WriteReg(5) + delay(20) + strobe(0x33) + delay(1000)`；
  - C.Fn F8 改值立即生效（+/-、回绕）；ID 改值仍立即重设；item<6 保持原厂行为；
  - 原厂镜像 F8 改值**不会**重设同步字（自证 hook 确实新增了立即生效）；
  - 读者屏蔽：level 查表在 F8=1/0 下返回相同值，原厂会切备用表；
  - 静默清零阻断：退出路径后补丁保持 F8=1，原厂被清 0；
  - 持久化：记录 `+0x1C` 含 F8，加载后回填 `settings[7]`。
- `selftest.py --key 0xD798`：**ALL PASS**（全设备）。

风险：

1. **无实机验证**：静态 + Unicorn 只能证明「代码按预期执行」，真正的空口同步过滤
   必须真机验证；建议按安全阶梯先刷「只改同步字 + 即时生效」版本（模块 `full=False`）。
2. **去掉 SCAL + 1ms 延时**：只改同步数字匹配字、不改频率寄存器，理论上不需要重校准；
   若实机首包异常优先怀疑此处。
3. **F8 原厂「稳定色温模式」被复用**：F8=ON 时该功能固定为出厂 OFF 行为；
   不想牺牲它可改用其它 C.Fn 项（需重新分析读者）。
4. **16 位同步字不是密码学认证**：挡的是正常原厂设备误触发，SDR 抓包理论上可克隆。
5. **版本绑定**：`apply()` 强校验长度/sha256/每处原始字节；官方升级固件后需重新定位。
