# V1C 静态证据与复现（补丁点定位过程）

本文记录 V1C 补丁点的定位过程与可复现脚本，供复核/换版本时重新定位用。
结论已汇总进 [`../README.md`](../README.md)，这里只放**过程证据**。

> 前置：仓库根便携 Python（capstone 5.0.7）`tools\python\python.exe`；固件 `devices/v1c/firmware/V1C_V2.0.bin`。
>
> 本文按 **v5（C.Fn `LIGHT` 开关）** 更新；v4（ID=OFF）与 v5-STBY（中间版）时期的定位证据仍适用，
> 开关语义见 `../README.md` §5。V1C 的 C.Fn **不显示 F1..F12 编号**，菜单里只有名称。

---

## 1. 定位方法（从常量 50024 = 0x0000C368 入手）

1. 在镜像里搜 4 字节小端字面量 `68 c3 00 00`（= 50024）；
2. 找到引用它的 `ldr rX, [pc, #imm]`，回溯到函数入口；
3. 反汇编该函数：应能看到
   `adds r1, r0, #1`（除数 = ID+1）→ `bl __aeabi_uidiv` → 两次 `WriteReg(4/5, …)` →
   `delay(20)` → `strobe(0x33)`（SCAL）→ `delay(1000)`；
4. 确认「全镜像只出现一次 `0xC368` 字面量」且「只有该函数在运行期写寄存器 4/5」。

V1C 的结果：字面量在 **`0x080121F0`**（文件偏移 `0x0F1F0`），函数入口 **`0x080121BC`**，
下一函数 **`0x080121F4`**，函数体 **56 字节**。

## 2. 复现脚本（可直接粘贴）

```powershell
# 仓库根，打印 0x08012180..0x08012210 的反汇编 + 全镜像对 0x080121BC 的调用点
tools\python\python.exe -c @"
from capstone import Cs, CS_ARCH_ARM, CS_MODE_THUMB, CS_MODE_MCLASS
FW, BASE = r'devices/v1c/firmware/V1C_V2.0.bin', 0x08003000
d = open(FW, 'rb').read()
md = Cs(CS_ARCH_ARM, CS_MODE_THUMB | CS_MODE_MCLASS)
for ins in md.disasm(d[0x08012180-BASE:0x08012210-BASE], 0x08012180):
    print('%08X  %-26s %s %s' % (ins.address, ins.bytes.hex(' '), ins.mnemonic, ins.op_str))
md.skipdata = True
for ins in md.disasm(d, BASE):
    if ins.mnemonic == 'bl' and ins.op_str.strip() == '#0x80121bc':
        print('caller', hex(ins.address))
"@
```

## 3. 关键证据表

### 3.1 同步字函数原厂反汇编（摘要）

见 [`../README.md`](../README.md) §2.1；核心 3 点：
`50024/(ID+1)`（`__aeabi_uidiv`）、写 `reg4/reg5`、`delay(20)+SCAL(0x33)+delay(1000)` 收尾。

### 3.2 5 个调用点（全部位于同一镜像）

> 2026-11-08 独立审计（`re/audit_static.py`）用 CFG 前驱 + 反向数据流确认：
> 5 个调用点解析出的设置区基址都是 **`0x20001086`**，ID 字节 = **`RAM[0x2000108C]`**。
> 早期 `scan4.py` 的 `0x200004F5` 候选是回溯 bug（把 `ldrb r0,[rX,#6]` 的目的寄存器
> `r0` 当成了基址寄存器 `rX`），**不要再引用**。

| 调用点 | settings 基址 | ID 字节地址 |
|---|---|---|
| `0x08006274` | `0x20001086` | `0x2000108C` |
| `0x080066B2` | `0x20001086` | `0x2000108C` |
| `0x0800D484` | `0x20001086` | `0x2000108C` |
| `0x0800E0C2` | `0x20001086` | `0x2000108C` |
| `0x0800E138` | `0x20001086` | `0x2000108C` |

补丁函数只接收 `r0`（ID），**不依赖**这个 RAM 地址；该地址仅用于文档记录/UI 方案。

### 3.3 写寄存器 4/5 的全部位置（全镜像扫描）

| 调用点 | 写入寄存器 | 场景 |
|---|---|---|
| `0x0801549E` / `0x080154A6` | 4 / 5 | CC2500 初始化表（`0xC3/0x68`，随后被覆盖） |
| `0x080121CE` / `0x080121D6` | 4 / 5 | 同步字函数（唯一运行期写入） |

其它 `WriteReg` 调用只写 `0x00–0x2E`、`0x06`、`0x18`、`0x0D/0x0E/0x0F`、`0x3E`，**不写同步字**。

### 3.4 初始化覆盖顺序

`RF_Init(0x0800664C)` → `CC2500 初始化表(0x08015470)`（写 reg4=0xC3/reg5=0x68）→ …
→ `bl 0x080121BC`（按当前 ID 与 LIGHT 开关覆盖写 reg4/reg5）。所以只改 `0x080121BC` 就能覆盖全部设置路径。

### 3.5 C.Fn 设置区与开关项（`settings[8]` = LIGHT）

来源：`re/cfn_settings.py` + `keypatch/dev/v1c/CFN_SETTINGS.md`、`CFN_MENU.md`。

- 设置区基址 **`0x20001086`**：item n = `settings[n]`；ID = `settings[6]` = `0x2000108C`；
  本补丁开关 = **`settings[8]` = `0x2000108E`**（C.Fn 第 3 页第 1 行 `LIGHT`）；
- 最大值/回绕表 **`0x08018362`**，12 字节 `01 01 01 01 01 1F 63 01 02 06 01 01`
  → max = `1,1,1,1,1,31,99,1,2,6,1,1`（item0..11；12 项，`cmp #0xB` 边界遍布处理/显示/持久化路径）；
- **item8 = LIGHT（原厂造型灯模式，三档 `12sec/OFF/ON` = `0/1/2`）**：
  出厂默认 **0（12sec）**（`0x0800672C` 处 `strb` 写 0）、功能读者 **`0x080036DA` / `0x08003702`**
  （造型灯任务 `0x080036D4` 控制 GPIO），其余是菜单显示/save/load；
- 项名/显示形式：用户菜单**不显示 F 编号**，12 项 = **3 页 × 4 行**；第 3 页为
  `LIGHT, LCD, FEB ACL, TX` → LIGHT 在第 3 页第 1 行；
- 注意：早期中间版用 item2 `STBY`，但其菜单 ON/OFF 与 settings 值反相（`0=ON/1=OFF`），
  已改为 item8 `LIGHT`（`ON` = 值 2，直观）。item7 = BEEP（不是稳定色温）。

### 3.6 注入 hook、两个 gate、读者屏蔽（v5 新增补丁点）

| 补丁点 | 原厂 | 补丁后 | 证据 |
|---|---|---|---|
| 代码洞 `0x08017944` | 234 B 连续 `0x00`（到 `0x08017A2D`） | 前 10 B 写注入代码 | 全镜像 BL/分支/LDR/绝对地址引用 0 处（`re/cfn_cave.py`） |
| gate `0x0800625C`（C.Fn 递减） | `06 29 08 d0`（`cmp r1,#6; beq sync`） | `11 f0 72 fb`（`bl 0x08017944`） | 前驱确认入口 `r0` = settings 基址 |
| gate `0x0800D46E`（C.Fn 递增） | `06 29 07 d0` | `0a f0 69 fa` | 同上 |
| 读者 `0x080036DA`（造型灯任务 1） | `00 7a`（`ldrb r0,[r0,#8]`） | `00 20`（`movs r0,#0`） | `settings[8]` 功能读者 |
| 读者 `0x08003702`（造型灯任务 2） | `01 7a`（`ldrb r1,[r0,#8]`） | `00 21`（`movs r1,#0`） | 同一函数的第二个读者 |
| 读者保护 `0x0800A6FA`（无线解包） | `08 72`（`strb r2,[r1,#8]`） | `00 bf`（`nop`） | 解包路径会把紧凑结构写回 `settings[8]` |

注入代码（10 B）：`1f b5 80 79 fa f7 38 fc 1f bd`
= `push {r0-r4,lr}; ldrb r0,[r0,#6]; bl 0x080121BC; pop {r0-r4,pc}`。

### 3.7 代码洞（注入区）

| 地址 | 连续 0 长度 | 引用检查 | 结论 |
|---|---|---|---|
| `0x08017944` | 234 B（到 `0x08017A2D`） | 无 BL/分支/LDR 字面量/全镜像绝对地址（含 `|1` 变体） | **可用**（本补丁用前 10 B） |
| `0x08017D28` | 222 B（到 `0x08017E05`） | 同上 | 可用（备用） |
| `0x0801749E`（57 B）/ `0x08016F0A`（36 B）/ `0x08016F42`（29 B） | — | 有字面量/分支引用 | **不可用** |
