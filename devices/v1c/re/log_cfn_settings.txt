3. 设置持久化、记录布局、出厂默认（独立确认）
==============================================================================
save 记录 builder : 0x08005EF0（settings 拷贝段 0x08006004..0x08006066）
load/expand 函数  : 0x080158B0（0x080159C4 起写 settings[0..0xD]）
出厂默认函数      : 0x080066D0（0x08006722..0x0800673A 写 settings[0..0xB]）
加载/默认任务     : 0x0800FEF8（槽位 0x0801F000+slot*100，头部 0x5C 合法标记）

记录偏移 -> settings 映射（save/load 两侧指令推导）:
  record[0x2E..0x2F] = settings[0..1]
  record[0x30..0x33] = settings[2..5]
  record[0x34..0x37] = settings[6..9]
  record[0x38..0x3B] = settings[10..13]

4. 可复用 C.Fn 开关项评估与推荐（含 mask / hook 方案）
==============================================================================
推荐排序（item 号 = settings 索引，F 号 = item+1）:
  item2  F3  STBY     : 首选：F3 STBY；默认 0=普通、显示 OFF/ON；唯一功能读者 0x080124DC，mask 成 movs r0,#0 即恢复出厂待机行为；不涉及 RF/闪光/GPIO 输出
  item3  F4  RX STBY  : 次选：F4 RX STBY；默认 0；唯一功能读者 0x08012528，mask 后仅影响待机超时阈值；与 F3 同一待机任务，改动更局部
  item0  F1  m/ft     : 低风险但 UX 差：F1 m/ft 只有显示读者 0x0800744E/0x08015D56，无硬件动作；但菜单显示 m/ft 而非 ON/OFF，作为开关不直观
  item8  F9  LIGHT    : 可用：F9 LIGHT；默认 0；应用读者 0x080036D4 需 mask；max=2（多一个状态），且会失去原厂造型灯 C.Fn 功能
  item10 F11 FEB ACL  : 待定：F11 FEB ACL；默认 0；读者 0x08005548 的语义未完全定性，暂不推荐
  item4  F5  SCAN     : 不推荐：F5 SCAN；默认 0，但 0x08012058 改值到 1 会触发扫描，0x0800FB2C/0x080053F4 会把 settings[4] 写回 0（密钥标志会被自清）
  item1  F2  AF       : 不推荐：F2 AF；默认 1，需反相语义（0=KEY）并 mask 0x08003654，且与 AF 辅助灯冲突
  item7  F8  BEEP     : 不推荐：F8 BEEP；默认 1；读者最多（16 处：应用 0x08003AE8 + 多路 UI/按键/显示），且 V1C 的 item7 不是 AD200 的稳定色温设置
  item11 F12 TX       : 不推荐：F12 TX；默认 1，0x200004F5 镜像被 RF/UI 多处读取，语义风险高
  item5  F6  CH       : 不适合：F6 CH；max 31、默认 20，非 0/1（射频频道）
  item6  F7  ID       : 不适合：F7 ID；这是当前设计的开关项，用户要求不再用 ID
  item9  F10 LCD      : 不适合：F10 LCD；max 6、默认 3，非 0/1（LCD 亮度/对比度）

★ 首选 item2 = F3 STBY（默认 0；菜单显示 OFF/ON）
  需 mask 的功能读者（2B ldrb -> movs，恢复出厂默认行为）:
    0x080124DC  原厂 90 78    -> 00 20     ldrb r0,[r2,#2] -> movs r0,#0（STBY=1 时不再关闭自动待机定时器）
  保留（不 mask）的读者：
    * 菜单渲染 0x08004B4E/0x08004B5E：显示 F3 的 ON/OFF（用户需要看到开关状态）
    * save 0x08006012 / load 0x080159D4：持久化（必须保留）
    * A6AC/A6DC 0x0800A6B4/0x0800A6E6：与 0x20001070 紧凑结构互拷（无线设置同步，风险见下）

  立即生效 hook（代码洞 0x08017944，10 字节）：
    1f b5 80 79 fa f7 38 fc 1f bd
    等价 C：push {r0-r4,lr}; r0 = settings[6]; rf_sync(id); pop {r0-r4,pc}
  函数门兜底（原厂 4B cmp/beq -> 4B bl hook）:
    0x0800625C  原厂 06 29 08 d0 (当前 06 29 08 d0) -> 11 f0 72 fb  dec 处理 0x0800625C: cmp r1,#6; beq -> bl hook
    0x0800D46E  原厂 06 29 07 d0 (当前 06 29 07 d0) -> 0a f0 69 fa  inc 处理 0x0800D46E: cmp r1,#6; beq -> bl hook

  说明：hook 在每次 C.Fn 改值（dec/inc 的改值分支）无条件调用同步字函数；
  原厂 ID(item6) 改值立即同步的行为保留；chosen item 改值也立即同步。
  hook 入口 r0=settings 基址（0x0800625C / 0x0800D46E 已用 CFG+数据流确认），
  故可直接 ldrb r0,[r0,#6] 取 ID，无需额外字面量。

  风险：item2 属于 A6AC/A6DC 的无线设置紧凑结构（settings[2] <-> 0x20001071），
  触发器等外部设置同步可能覆盖密钥标志；同理 0x0800DCDC 会写 settings[1..11]。
  需要 Lead 在模拟/真机验证该路径；必要时把对应写点也 mask 为保留 bit。
